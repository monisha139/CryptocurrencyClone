# Cryptocurrency Clone 💰

## 📌 Project Overview

Cryptocurrency Clone is a Java-based desktop application developed as part of my Java Programming Internship at SQROCK IT SOLUTIONS.

The application allows users to register, login, view cryptocurrencies, search coins, manage their watchlist, and maintain their cryptocurrency portfolio.

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Git
- GitHub
- MySQL Connector/J

## ✨ Key Features

- User Registration
- User Login
- Cryptocurrency Listing
- Search Cryptocurrency by Name and Symbol
- View Cryptocurrency Details
- Add Cryptocurrency to Watchlist
- View Watchlist
- Add Cryptocurrency to Portfolio
- View Portfolio
- Market Overview
- MySQL Database Integration

## ▶️ How to Run

1. Install Java JDK 17 or later.
2. Install MySQL.
3. Create the cryptocurrency_clone database.
4. Create the required tables.
5. Add MySQL Connector/J to the project.
6. Configure the database connection in DatabaseConnection.java.
7. Run RegisterFrame.java or LoginFrame.java.
8. Register or login to access the Cryptocurrency Dashboard.
